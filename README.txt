Red Feather - mod NeoForge 1.21.1

Build :
1. Installer JDK 21
2. Copier gradlew, gradlew.bat et le dossier gradle/ depuis le MDK officiel
   NeoForge 1.21.1 (https://github.com/neoforged/MDK), ou lancer `gradle wrapper`
3. ./gradlew build   -> le .jar est dans build/libs/
   ./gradlew runClient pour tester directement

Reglages : constantes en haut de RedFeatherSpeedHandler.java
